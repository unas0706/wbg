How to Fill This Template with Copilot

Step-by-step workflow — keep your confidential PDFs local, use Copilot safely

🔒 Why This Workflow Is Safe & Professional

  1. Claude designed the template — structure, design system, section layout, flow diagram SVG components. Zero project-specific data was shared with Claude. This is completely safe to say publicly.
  2. Microsoft Copilot fills the content — Copilot in Edge / Word / M365 reads your PDFs locally on your work laptop. Data stays inside your organisation's M365 boundary. World Bank data never leaves your network.
  3. You review and paste — you verify every generated section before pasting into the template. You stay in control.
  4. The output is a professional HTML doc site — opens in any browser, no server needed, shareable with your manager.
⚠️
Important: Never paste confidential project details into Claude.ai, ChatGPT, or any public AI tool. Only use Microsoft Copilot (M365) or GitHub Copilot (enterprise-licensed) for content generation from internal documents.

Step-by-Step Fill Workflow

1

Open your PDF in Microsoft Edge or Word

Open the technical documentation PDF (or multiple PDFs) on your work laptop. Edge has Copilot built-in via the sidebar — click the Copilot icon on the right.

2

Open this HTML file in a text editor (VS Code recommended)

Open documentation-template.html in VS Code. You'll see purple hint blocks throughout — each one has a ready-made Copilot prompt you can copy and use.

3

Use the Copilot prompts in each section

Every section of this template has a purple 🤖 Copilot Prompt box. Copy the prompt text, paste into Copilot sidebar (with your PDF open), get the result, and paste into the template HTML replacing the [placeholder] text.

4

Fill the stats bar (Home page — stat numbers)

Copilot prompt: "How many controllers, endpoints, services, and external integrations does this system have? Give me only numbers."

5

Generate tables from the PDF

For API endpoint tables, Copilot prompt: "List all endpoints in [ControllerName] controller with HTTP method, path, permission required, and what it returns. Format as a table."

6

Fill the sequence flow diagrams

For the SVG sequence diagrams, Copilot prompt: "Describe the complete step-by-step flow for [operation name] — from the UI request through middleware, controller, MediatR, handler, service, and database. Include what each step does." Then update the SVG participant labels and message text accordingly.

7

Generate the Glossary

Copilot prompt: "List all acronyms, abbreviations, and domain-specific terms used in this document with a brief definition of each. Format as term: definition pairs."

8

Fill configuration section

Copilot prompt: "List all environment variables, configuration keys, and Azure Key Vault secrets mentioned in this document with their purpose. Do not include actual values."

9

Remove all purple Copilot hint blocks

Once a section is filled, delete the <div class="hint">...</div> block above it. The final doc should have no purple hint boxes — those are your working notes only.

10

Open in browser and verify

Double-click the HTML file to open in Chrome/Edge. Navigate every section, check the search bar works, test dark mode. Share the single HTML file with your manager — no server or deployment needed.
