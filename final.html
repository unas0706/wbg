Quick Start Guide

Developer onboarding: authentication, first API call, and key conventions

Adding a New Feature — Correct Order

Every endpoint must follow the CQRS chain. Never skip steps or inject services/repositories across layer boundaries.

1

Define Response

NewFeatureResponse.cs in Responses/Domain/ — inherit ResponseBase, add Result field.

2

Create Query or Command

NewFeatureQuery.cs or NewFeatureCommand.cs — implement IRequest<NewFeatureResponse>.

3

Write Validator

NewFeatureCommandValidator.cs — AbstractValidator<T> with RuleFor() calls. Use .When() for conditional rules.

4

Define Interface

INewFeatureService.cs — single method signature Task<ReturnType> MethodName(params).

5

Implement Service

NewFeatureService.cs — all business logic lives here. Constructor-inject repositories and other services.

6

Register in DI

In Startup.cs ConfigureServices(): services.AddTransient<INewFeatureService, NewFeatureService>();

7

Create Handler

Implement IRequestHandler<TQuery, TResponse>. Constructor-inject INewFeatureService. Call service, wrap response, return.

8

Add Mapper (if needed)

NewFeatureMapperProfile.cs with CreateMap<Source, Dest>() and ForMember() overrides.

9

Add Controller Endpoint

In [DomainName]Controller — [HttpGet/Post] method with [PolicyAuthorize]. Call _mediator.Send(). Zero business logic.

10

Test via Swagger

Navigate to /api/esrd/swagger. Authenticate with Bearer token. Find endpoint. Test with sample input.

⚠️

CRITICAL: Never inject a Service directly into a Controller. Never inject a Repository directly into a Handler. The chain Controller → MediatR → Handler → Service → Repository must be respected at all times.

System Overview

About MIGA, Portal purpose, module inventory, and technology stack

The MIGA E&S Portal 2.0 is an enterprise-grade web application for the Multilateral Investment Guarantee Agency (MIGA), World Bank Group. It serves as the central platform for managing the full lifecycle of guaranteed investment projects, with deep focus on Environmental and Social (E&S) risk management, compliance monitoring, and due diligence against IFC Performance Standards PS1–PS8.

MIGA's mandate is to promote foreign direct investment in developing countries via political risk insurance. For every project it guarantees, MIGA must assess and mitigate potential environmental and social risks.

Standard API Response Envelope

Every endpoint returns the same JSON envelope. Always check STATUS_CODE first — HTTP 200 can still have STATUS_CODE 500 inside.

JSON — Success Response
{
  "STATUS": "Success",      // Always "Success" by convention
  "STATUS_CODE": 0,       // 0 = success | 500 = error
  "NOTIFICATIONS": [],    // Error/info messages if any
  "Result": [ ... ]       // The actual data payload
}

// Error response — note STATUS is still "Success" but STATUS_CODE is 500
{
  "STATUS": "Success",
  "STATUS_CODE": 500,
  "NOTIFICATIONS": [
    { "Code": "500", "Message": "EsId not found", "NotificationType": 500 }
  ],
  "Result": null
}
ℹ️

File download endpoints (DownloadXxxReport) do NOT return JSON. They return FileStreamResult: a binary .xlsx stream with Content-Disposition header. The browser triggers a Save File dialog automatically.

5

6
Review

Specialist completes GBV risk questionnaire. System calculates GBV Risk Score and Rating (Low/Medium/High FI).

8
Portfolio
Guarantee Issuance
Management review → approved projects move to Portfolio via ProjectPhaseUpdateEvent on Azure Service Bus.
9
Portfolio
Ongoing Monitoring
Regular E&S monitoring: AMR Review, Site Visit (physical/virtual), Client Meeting. ESRR(M) updated each cycle.
10
Portfolio
ESAP Completion
Specialist verifies guarantee holder completion. Missed deadlines trigger automated email reminders.
11
Portfolio

12

Project Closure
Guarantee expires → moves to Shelved (181 records). All data retained read-only. Status: DECLINED, WITHDRAWN, etc.

Read-only archive of terminated and declined projects

Shelved Projects are investment projects that were declined, withdrawn, not going forward, or deselected by MIGA. The system currently holds 181 shelved records. All data is retained read-only for compliance purposes — no edit operations are permitted.

Flow Diagrams

Complete end-to-end request flows from browser click to database and back

CQRS Request Flow — Every Operation

CQRS + MediatR — Standard Request Pipeline
UI
React.js Frontend

HTTP POST/GET with Authorization: Bearer <JWT> header + JSON body

MW
Azure AD JWT Middleware

UseAuthentication() validates Bearer token — signature, expiry, audience. Invalid = HTTP 401 immediately.

CTL
ASP.NET Core Controller

[PolicyAuthorize(ESRD, ReadAll|EditAll)] checked. Body deserialized. Calls _mediator.Send(query) — ZERO business logic here.

VAL
FluentValidation (Auto-runs)

Runs BEFORE handler executes. On failure: HTTP 400 returned immediately. Handler never runs.

MED
MediatR Routes to Handler

Resolves IRequestHandler<TQuery, TResponse> via Autofac DI container.

HND
Handler

Calls exactly ONE service method. Wraps result in response envelope. No business logic here.

1
UI — User Clicks "Portfolio Projects"

React triggers HTTP POST /api/esrd/Projects/GetPortfolioProjects with Bearer header + JSON filter body

2
Azure AD JWT Validation

Token signature, expiry, audience checked. Invalid = HTTP 401 immediately.

3
ProjectsController

[PolicyAuthorize(ESRD, ReadAll)] checked. Body → PortfolioProjectsQuery. Calls _mediator.Send().

4
PortfolioProjectsQueryHandler

Calls IPortfolioProjectsService.GetPortfolioProjects(request). Awaits result.

5
Get Portfolio Phase Code from Cache

_commonService.GetEsMasterData(ProjectPhase) — integer phase code from in-memory cache (30-min TTL).

6
Build LINQ Filter Predicate

BuildEsTablePredicateForPortfolioProjects() — dynamic expression tree. Applies only filters present in query.

7
Query PostgreSQL

EF Core SELECT from es_header with JOINs on monitoring, ESRR ratings, team info.

8
Call MIGA Portal Integration Service

HTTP GET to MPMIntegrationServiceUrl. Gets all project numbers. Identifies unassigned projects.

9
Parallel Data Fetch — Task.WhenAll

Simultaneously: (a) full contract/application data, (b) cost codes. Both calls run in parallel for efficiency.

10
Fetch Team & Lookup Data

Team user details, IFC Track codes, ES Score lookup tables from _commonService.GetEsMasterData().

11
Map & Merge — 80+ Fields Per Project

MapPortfolioProjectInformationResult() — joins ESRD DB data with Integration data. AutoMapper populates all 80+ fields.

12
Response Returned to UI

Handler wraps list in envelope. ASP.NET Core serializes to JSON (PascalCase). HTTP 200. React renders portfolio grid.

Save Monitoring Activity

SaveMonitoringActivity — Multi-Step Save Flow
1
UI — Specialist Fills Monitoring Form

Checks AMR Review flag, enters dates. Optionally adds SiteVisit, VirtualMonitoring, ClientMeeting. Clicks Save.

2
JWT + EditAll Permission Check

Bearer token validated. [PolicyAuthorize(ESRD, EditAll)] checked. [FromForm] multipart body deserialized.

3
FluentValidation — 12 Conditional Rules

If AmrReviewFlag=true: AmrFromDate, AmrToDate, AmrDueDate, AmrReceivedDate ALL required. If SiteVisitFlag=true: From/ToDate required.

4
Verify EsId Exists in Database

GetAsync<EsHeader>(x => x.Id == esId). Not found → notification "EsId not found", STATUS_CODE=500.

5
Verify Active Contracts Exist

CheckIfProjectContainsContracts(projectNumber) — HTTP call to Integration Service. No contracts = cannot save.

6
Questionnaire Seeding

First-ever record: copy DD questionnaire responses to Monitoring. Prior records exist: copy most recent monitoring responses.

7
INSERT EsMonitoring to PostgreSQL

EF Core InsertAsync<EsMonitoring>(). Auto-sets CreatedBy (from JWT UPI), CreatedOn, IsDeleted=false.

8
Response Returned

{ ProjectStageId: 4521, STATUS_CODE: 0 }. React refreshes monitoring list. Dashboard AMR counters auto-update.

Docs / IFC Performance Standards
14

IFC Performance Standards PS1–PS8

E&S risk management standards against which all MIGA-guaranteed projects are assessed

PS1
Assessment & Management of E&S Risks

The foundational standard. Requires an ESMS, stakeholder engagement, and grievance mechanisms. Applies to ALL projects.

PS2
Labor & Working Conditions

Worker rights, supply chain labor standards, occupational health and safety, non-discrimination and equal opportunity requirements.

PS3
Resource Efficiency & Pollution Prevention

GHG emissions tracking, pollution controls, hazardous materials management, waste minimization.

PS4
Community Health, Safety & Security

Infrastructure safety, emergency preparedness, security forces code of conduct. Protects communities from project-related harms.

PS5
Land Acquisition & Involuntary Resettlement

Compensation at replacement cost, livelihood restoration, Resettlement Action Plans (RAPs). Applies when land acquisition involved.

PS6
Biodiversity Conservation

Critical habitat assessment, biodiversity offsets, sustainable use of natural resources. Linked to Nature Finance assessments.

PS7
Indigenous Peoples

Free, Prior and Informed Consent (FPIC), cultural heritage protection, benefit sharing. Applies when indigenous communities affected.

PS8
Cultural Heritage

Protection of tangible and intangible cultural heritage, chance finds procedures during construction.

Business Glossary

Key terms, acronyms, and technical definitions used throughout the MIGA E&S Portal

AMRAnnual Monitoring Report — submitted by guarantee holders annually documenting E&S performance against ESAP requirements
AsposeCommercial library for Excel (.xlsx) and PDF report generation on the server — used for all 18+ downloadable reports
AutofacAdvanced DI container that overrides default ASP.NET Core DI, providing more features for dependency resolution
AutoMapperLibrary that automatically copies properties between two object types by name matching — 30 profiles in use
CAOCompliance Advisor Ombudsman — independent IFC/MIGA oversight function handling E&S performance complaints
CQRSCommand Query Responsibility Segregation — architecture pattern separating read (Query) and write (Command) operations
DDDue Diligence — the E&S assessment conducted on pipeline projects before guarantee issuance
ESAPEnvironmental & Social Action Plan — contractual actions guarantee holders must complete as a condition of the guarantee
ESDDEnvironmental & Social Due Diligence — the full assessment process for pipeline projects
ESMSEnvironmental and Social Management System — risk management framework at the project or enterprise level
ESRR(D)Environmental & Social Risk Rating at Due Diligence stage — generated from factor scores (Management, Performance, Communication)
ESRR(M)Environmental & Social Risk Rating at Monitoring stage — updated during each monitoring activity cycle
EsIdInternal E&S Portal integer ID for each project — primary key in the es_header PostgreSQL table
EsStageProject stage code: 'DD' (Due Diligence pipeline) or 'MN' (Monitoring portfolio)
FPICFree, Prior and Informed Consent — requirement under PS7 for projects affecting Indigenous Peoples
GBVGender-Based Violence — specific E&S risk category assessed for all MIGA-guaranteed projects via dedicated questionnaire
HandlerMediatR handler class that receives a Query or Command and delegates to exactly one Service method — no business logic here
IFC Track BIFC categorization for Financial Intermediary projects requiring enhanced E&S monitoring requirements
Key VaultAzure Key Vault — secure secret store for DB connection strings, API keys, and subscription keys — never in code
Malena AIIFC's AI document analysis service at malenaapiext.ifc.org — provides sentence-level E&S risk classification
MediatROpen-source .NET library implementing the Mediator pattern for CQRS message dispatch between Controller and Handler
MIGAMultilateral Investment Guarantee Agency — World Bank Group member providing political risk insurance (PRI)
MSVMonitoring Site Visit — physical or virtual visit to a project site for E&S compliance verification
PollyResilience library providing HTTP retry policies — used for 3-retry on Malena AI service HTTP calls
PolicyAuthorizeCustom World Bank attribute combining Azure AD JWT authentication + ESRD permission code check
PS1–PS8IFC Performance Standards 1–8 — E&S risk management standards against which all MIGA-guaranteed projects are assessed
Service BusAzure Service Bus — async messaging backbone for domain events between MIGA microservices
UPIUnique Person Identifier — World Bank's internal integer user ID used for all user references in the system
